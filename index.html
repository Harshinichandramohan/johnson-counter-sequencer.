What is a Johnson Sequence Counter?

A Johnson Counter is a type of shift register counter, also called a Twisted Ring Counter.

In this counter, the inverted output of the last flip-flop is connected back to the input of the first flip-flop.

A 4-bit Johnson Counter produces 8 different states before repeating.

Johnson Counter Sequence:

0000 → 1000 → 1100 → 1110 → 1111 → 0111 → 0011 → 0001 → 0000

In this project, each Johnson Counter state represents a different event in the traffic signal system.
